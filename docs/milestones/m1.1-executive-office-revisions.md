# Milestone 1.1 — Executive Office Revisions

_Executive summary · 21 July 2026_

A refinement pass based on Executive Office review. No redesign, no scope
expansion; every existing architectural decision retained.

## What changed

1. **Executive Brief (was Home).** A dominant **Today's Priorities** section
   now opens the screen: the 3–5 items worth the Director's next 30 minutes,
   ranked by urgency and impact. Each carries title, why it matters, estimated
   time, a deterministic confidence level, and a recommended action, plus a
   total-minutes line ("About 53 minutes to clear all 5"). Below it, retained
   and re-ordered: since-your-last-brief highlights and risks, position
   metrics, deliverables ready for review, officer updates, and work in motion.
2. **Navigation.** New order: Executive Brief · Organization · Work ·
   Decisions · Knowledge · Executive Assistant. "Officers" became
   **Organization** (`/organization`); "Activity" became **Knowledge**
   (`/knowledge`), which carries the organizational record and states plainly
   that it becomes the Organizational Mind in future milestones. Old routes
   redirect permanently.
3. **Executive Assistant workspace.** No longer just a chat: conversation on
   the left, with panels for **Pending Decisions** (live), and
   **Recommendations / Research / Drafts** (clearly-labelled sample content
   establishing the future layout).
4. **Canonical model protection.** ADR 0004 records that the current entity
   model is an engineering implementation, not the Organizational Twin
   ontology; the domain types header points to it.
5. **Knowledge metadata.** All nine major entities can now carry an optional
   `meta` field (provenance, confidence, evidence, relatedEntities, history).
   Nothing reads or writes it — purely architectural preparation.
6. **Language & polish.** Dashboard/monitoring vocabulary replaced with
   direct / decide / execute / commitments / outcomes language; loading
   skeletons match the new layout; mobile nav uses short labels.

## Why

The Brief should answer one question — *"if I only have 30 minutes today,
what should I focus on?"* — without the Director reading more than one
screen. The rest of the changes align naming and posture with an executive
operating system rather than a reporting surface, and protect the platform's
future ontology from MVP pragmatism.

## Architecture impact

Minimal and additive. One new pure domain function (`todaysPriorities`), one
new optional type (`KnowledgeMetadata`), three route renames with permanent
redirects, two new presentational components, one ADR. No new dependencies, no
schema/persistence changes, no provider changes. Backward compatible: old data
files, old URLs, and all existing API routes work unchanged.

## Technical debt

Unchanged from M1 (JSON store, no CI, custom test resolver, `console`
namespace), plus one new note: the EA workspace's Recommendations/Research/
Drafts panels contain hand-written sample content that must be replaced when
EA reasoning lands — each is labelled "Sample" in the UI so it cannot be
mistaken for live output.

## Outstanding decisions

Unchanged from M1: persistence backend, authentication approach, first live
`AgentProvider`, and the six in-app decisions awaiting the Director.

## Tests

53 tests passing (44 from M1 + 9 new for priority ranking: ordering,
unblock-boost, dedupe against covered blockers, confidence derivation, empty
state, critical-first). Clean typecheck, lint, production build, and a runtime
smoke test of every route, both redirects, and the Brief's rendered content.

## Suggested Milestone 2

Unchanged in substance: durable database behind `ConsoleRepository`, first
live `AgentProvider`, authentication, CI + preview deploys, deliverable
versioning/diff and decision notifications — now with the EA workspace panels
as the natural surface for the first real EA reasoning.
